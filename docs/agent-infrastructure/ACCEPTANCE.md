# Revised acceptance and evidence matrix

Version 1 · 7 November 2026. All gates below are **planned / not run for the expanded product**, unless explicitly marked otherwise. The existing 49 foundation Worker/domain tests and 10 browser tests do not establish inbox, scheduling, real capture, AI or recap acceptance. Test names below describe required scenarios, not files that already exist.

Use statuses `planned`, `implemented/not run`, `pass`, `fail`, `blocked`. A pass requires command/output, source commit, environment/image/model versions where relevant and a redacted evidence pointer. Participant recordings, raw mail, addresses, credentials and private transcript content must not be committed to a public PR.

## Evidence record

For each ID append:

- Status and exact requirement interpretation.
- Source commit; test path/command/output, or reason blocked/not run.
- Local fixtures versus actual preview/production services.
- Applicable image digest, deployed version, model/schema version and resource configuration read-back.
- Redacted private evidence reference and reviewer; no participant audio/mail in public artifacts.
- Remaining limitation and owner action, if any.

## Document-only validation of this revision

The revision itself requires valid relative Markdown links, an internally consistent scope/phase/gate mapping, preserved original handoff manifests, and a clean diff/secret scan. Those checks validate documentation only. They must never check off the runtime gates above.
