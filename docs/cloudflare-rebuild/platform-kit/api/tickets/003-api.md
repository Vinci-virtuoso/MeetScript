## Context

## Acceptance criteria (Gherkin)
- **Given** a write route **when** the body does not match its zod schema **then** the answer is 400 `validation_error` with `issues` listing the failing paths and nothing is written.
- **Given** any `/api/*` route **when** it fails **then** the body is `{ error, message }` with the status the contract names, and an unknown path answers 404 `not_found`.
- **Given** the Worker **when** a client requests `GET /api/openapi.json` **then** every `/api/*` route defined in `src/server/routes/` appears with its schemas.
- **Given** a state-changing request with a foreign `Origin` **when** it reaches `/api/*` **then** the answer is 403 `forbidden_origin`.
- **Given** a bare `OPTIONS` request **when** it reaches a route **then** the answer is the route's 405, and a real preflight answers 204 with the allowlist headers.
